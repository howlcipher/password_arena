GLOBAL THERMONUCLEAR WAR / PASSWORD ARENA

> WHY_THIS_PROJECT_EXISTS

The project explores a practical question:

Can an attacker agent improve its strategy while a defender agent learns that predictable human-style passwords are weaker than cryptographically secure randomness?

The MVP deliberately uses transparent, rule-based agents. That makes the experiment reproducible and establishes a trustworthy baseline before optional LLM or reinforcement-learning agents are added.

> WHAT_IT_MEASURES

  • Estimated entropy and structural penalties
  • Attacker success rate
  • Guesses used per round
  • Runtime per attack
  • Attacker strategy selection
  • Defender password-family progression
  • Agent observations across rounds
  • Two-sided audit reports

> CURRENT_ARCHITECTURE

  • Adaptive defender: escalates from dictionary words to CSPRNG-generated passwords.
  • Adaptive attacker: ranks common-password, mutation, passphrase, and bounded-random strategies.
  • Evaluator: calculates strength indicators and captures metrics.
  • Dashboard: visualizes learning curves and exports JSON.

> QUICK_START_SEQUENCE

bash root@wopr:~

pip install -e ".[all]"

# RUN THE ARENA

  --report results/run.md
